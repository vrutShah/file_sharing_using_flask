### Utility Functions

#### `get_local_ip`

```python
def get_local_ip() -> str:
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.connect(("8.8.8.8", 80))
        ip = s.getsockname()[0]
        s.close()
        return ip
    except Exception:
        return "127.0.0.1"
```

- Creates a UDP socket and connects to Google's public DNS server (8.8.8.8) to determine the local machine's IP address.
- Returns the connected socket's own IP (local IP address).
- If any failure, returns localhost `127.0.0.1`.
- This is used to show URLs for downloads accessible from the local network.

#### `make_qr_b64`

```python
def make_qr_b64(url: str) -> str:
    qr = qrcode.QRCode(
        version=1,
        error_correction=qrcode.constants.ERROR_CORRECT_H,
        box_size=8,
        border=3,
    )
    qr.add_data(url)
    qr.make(fit=True)
    img = qr.make_image(fill_color="#0a0a0f", back_color="#f0f4ff")
    buf = io.BytesIO()
    img.save(buf, format="PNG")
    return base64.b64encode(buf.getvalue()).decode()
```

- Generates a QR code image encoding the given URL.
- Configures QR size, error correction, colors.
- Saves image to an in-memory buffer (`BytesIO`).
- Returns the image encoded as a base64 string.
- This lets the app embed the QR code image directly into HTML (no separate image file).

#### `human_size`

```python
def human_size(n: int) -> str:
    for unit in ("B", "KB", "MB", "GB"):
        if n < 1024:
            return f"{n:.1f} {unit}"
        n /= 1024
    return f"{n:.1f} TB"
```

- Converts a file size in bytes to a human-readable string with units.
- For example, 2048 bytes becomes `2.0 KB`, 1048576 bytes becomes `1.0 MB`.
- Handles up to terabytes.

#### Route: `/upload` (upload files)

```python
@app.route("/upload", methods=["POST"])
def upload():
    file = request.files.get("file")
    description = request.form.get("description", "").strip()[:200]

    if not file or file.filename == "":
        return jsonify({"error": "No file selected."}), 400

    original_name = secure_filename(file.filename)
    file_id       = uuid.uuid4().hex
    ext           = os.path.splitext(original_name)[1]
    stored_name   = f"{file_id}{ext}"
    save_path     = os.path.join(UPLOAD_DIR, stored_name)

    file.save(save_path)
    size = os.path.getsize(save_path)

    meta = load_meta()
    meta[file_id] = {
        "original_name": original_name,
        "stored_name":   stored_name,
        "description":   description,
        "size":          size,
        "size_human":    human_size(size),
    }
    save_meta(meta)

    ip       = get_local_ip()
    port     = request.environ.get("SERVER_PORT", 5000)
    base_url = f"http://{ip}:{port}"
    dl_url   = f"{base_url}/d/{file_id}"
    qr_b64   = make_qr_b64(dl_url)

    return jsonify({
        "file_id":       file_id,
        "original_name": original_name,
        "description":   description,
        "size_human":    human_size(size),
        "download_url":  dl_url,
        "qr_b64":        qr_b64,
    })
```

1. Accepts a POST request with an uploaded file (`file`) and an optional description.
2. Validates that a file is chosen.
3. Sanitizes the original filename.
4. Generates a unique file ID (UUID).
5. Stores the file on disk as `<file_id>.<extension>`.
6. Gets the file size, updates metadata dict, writes to `metadata.json`.
7. Constructs a download URL based on local IP and server port.
8. Creates a base64 QR code image encoding the download URL.
9. Returns a JSON response with file info, download link, and QR code image.

This is the core upload logic.

- Renders `download.html` template to display file info and QR for download.

```python
@app.route("/d/<file_id>/file")
def download_file(file_id):
    meta = load_meta()
    if file_id not in meta:
        abort(404)
    info = meta[file_id]
    return send_from_directory(
        UPLOAD_DIR,
        info["stored_name"],
        as_attachment=True,
        download_name=info["original_name"],
    )
```

- Sends the actual file content for downloading.
- Looks up metadata for the file, returns 404 if not found.
- Uses `send_from_directory` with `as_attachment=True` to serve the file as a downloaded attachment.
- The downloaded file retains the original filename.
